# 사이트 설계도(PRD) — 윤담온 (수제식혜 소개 사이트)

작성일: 2026-11-03 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
철원오대쌀로 직접 만든 수제 살얼음 식혜를 개인에게는 택배로, 단체에는 행사 답례품으로 판매하는 곳.

## 2. 손님
- 누가: 집에서 마실 개인 손님, 선물하려는 개인, 행사 답례품을 찾는 단체
- 어디서 알고 오나: 인스타그램, 네이버 검색·블로그

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격·용량 (한 병/세트 가격, 단체 수량별 가격)
2. 배송·보관·유통기한 (언제 도착하는지, 얼마나 두고 마실 수 있는지)
3. 재료·단맛 정도 (무엇으로 만드는지, 얼마나 단지)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 제품 사진: `docs/사진/제품-병식혜.jpg` — 라벨 붙은 병 식혜가 줄지어 놓인 사진 (첫 화면용)
- 만드는 과정 사진: `docs/사진/만드는과정-가마솥.webp` — 큰 솥 네 개에서 식혜를 끓이는 사진 ("직접 만들어요" 구역용)
- 라벨 문구: "철원오대쌀로 만든 수제 살얼음 식혜" · 라벨의 브랜드 표시 "소이온점"은 사이트 이름으로 쓰지 않음
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 주문 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로) — 한 페이지
1. 첫 화면 — 한 문장 + [주문 문의하기] 버튼
2. 이렇게 주문할 수 있어요 — 개인 택배 / 선물 / 단체 답례품 세 가지 안내
3. 직접 만들어요 — 솥에서 끓이는 사진 + "철원오대쌀로 만든 수제 살얼음 식혜"
4. 자주 묻는 것 — 가격·용량 / 배송·보관·유통기한 / 재료·단맛 (정하지 않은 값은 "준비 중")
5. 후기 자리 (비워 둠)
6. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 수량·희망 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격·용량: (미정 — 사이트에는 "준비 중")
- 유통기한·보관: (미정 — 사이트에는 "준비 중")
- 배송 지역·기간: (미정 — 사이트에는 "준비 중")
- 연락 방법: (미정 — 우선 문의 폼으로 받음)
- 재료: 철원오대쌀 (라벨 문구 그대로)
- 제품 이름: 수제 살얼음 식혜 (라벨 문구 그대로)
- 단맛 정도: (미정)
- 사이트 이름: 윤담온

## 9. 이번에 넣지 않을 것
- 회원가입·로그인 (다음에)
- 온라인 결제·장바구니 (다음에)
- 사진 올리기, 알림 메일 (다음에)

## 10. 첫 화면 한 문장 후보
1. 철원오대쌀로 직접 만든 수제 살얼음 식혜, 택배로 받아 보세요.
2. 마시는 사람도, 받는 사람도 기분 좋은 철원오대쌀 살얼음 식혜.
3. 행사 답례품, 직접 끓인 수제 살얼음 식혜로 준비하세요.

## 11. 다음에 할 것
- 가격·용량·유통기한·배송 정보 정해서 "준비 중" 채우기
- 선물 포장·단체 답례품 사진이 생기면 추가하기
- 실제 후기가 생기면 후기 자리에 넣기
- 인스타그램·네이버 블로그에 사이트 주소 걸기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
